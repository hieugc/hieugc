# UI/UX Prompt for Editing CV / Portfolio Interface

## Role
You are a **UI/UX Designer and Frontend Engineer**.

Your task is to redesign a **personal CV / Portfolio website** with a **two-column layout (left sidebar + right main content)**.  
The style should be **professional, minimal, and modern**, suitable for a **.NET Backend Developer**.

---

## 1. Overall Layout
- Desktop-first design
- Fixed **two-column layout**
  - **Left sidebar: 30%**
  - **Right main content: 70%**
- Fully responsive:
  - Tablet: sidebar collapses
  - Mobile: sidebar moves to top or drawer menu

---

## 2. Left Sidebar (Profile & Skills)

### 2.1 Personal Information
- Circular avatar
- Full name (large, bold)
- Job title (e.g. *Backend .NET Developer*)
- Social links with icons:
  - GitHub
  - LinkedIn
  - Email

### 2.2 Basic Information
Displayed as a clean list:
- Email
- Phone number
- Date of birth

### 2.3 Skills (Grouped Clearly)

**Architecture & Design**
- MVC Architecture
- Microservices Architecture (basic)
- RESTful API Design

**Backend**
- ASP.NET Core, ASP.NET MVC
- Entity Framework Core, LINQ
- Authentication & Authorization (JWT, Role-based)

**Frontend**
- HTML5, CSS3, JavaScript
- jQuery, Bootstrap

**Database**
- SQL Server, MySQL
- Stored Procedure, View, Query Optimization

**Tooling & Deployment**
- Git / GitLab
- IIS Deployment
- Postman (API testing)

**Others**
- Flutter (basic)
- AI-assisted tools (Claude, ChatGPT)

### 2.4 Action Button
- Prominent **Download CV** button
- Download icon
- Uses primary theme color

---

## 3. Right Main Content

### 3.1 Navigation Bar (Sticky)
Horizontal navigation menu with smooth scroll and active states:
- About Me
- Featured Projects
- Work Experience
- Education
- What Can I Do (Skills Summary)
- Contact Information

---

## 4. Section Content Details

### About Me
- Short professional summary
- Focus on backend development, system design, and API experience

### Featured Projects
- Card-based layout
- Each project includes:
  - Project name
  - Short description
  - Tech stack
  - GitHub / Demo link

### Work Experience
- Vertical timeline layout
- Each entry includes:
  - Company name
  - Duration
  - Role
  - Bullet-point responsibilities

### Education
- School name
- Major
- Study period

### What Can I Do
- High-level summary of capabilities:
  - Backend systems
  - API development
  - Database optimization
  - Deployment & maintenance
- Use icons where appropriate

### Contact Information
- Email
- Phone number
- Social links
- Clear call-to-action (Contact Me)

---

## 5. Design Guidelines
- Modern, readable typography
- Clear spacing and hierarchy
- Minimal color palette (1 primary color + neutral tones)
- Optimized for IT recruiters and technical reviewers
